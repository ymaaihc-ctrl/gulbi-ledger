# 굴비 가계부

천장의 굴비처럼 계획만큼만 쓰면 굴비(보상)가 쌓이는 자린고비 가계부. 빌드 도구 없는 모바일 PWA입니다.

## 실행

```
python -m http.server 8765      # http://localhost:8765
npm test                        # 계산 로직 테스트
```

## 친구에게 넘기기

1. 앱을 정적 호스팅(GitHub Pages 등)에 올린다.
2. 친구의 월 계획을 `private/friend-plan.json`에 적는다 (`private/`는 git에 올라가지 않음).
3. 설정 링크를 만든다.
   ```
   node tools/make-setup-link.js private/friend-plan.json https://<앱 주소>/
   ```
4. 친구에게 링크를 보낸다. 처음 열면 계획이 자동으로 들어가고, 링크의 `#setup=` 부분은 주소창에서 지워진다. 해시(#)는 서버로 전송되지 않는다.
5. 친구는 홈 화면에 추가해서 쓴다. 아이폰은 설치하지 않으면 7일 넘게 안 열 때 사파리가 기록을 지울 수 있다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `calc.js` | 순수 계산: 생활비 잔액, 오늘 한도, 받을 돈, 여유 자금, 굴비 보상, 입력 검증 |
| `db.js` | IndexedDB 저장, 휴지통 정리, 백업 내보내기/불러오기 |
| `app.js` | 화면 렌더와 상호작용 |
| `mascot.js` | 굴비 마스코트 SVG (행복/걱정/한 입 뜯김/졸림) |
| `sw.js` | 오프라인 캐시 |

## 데이터 정책

- 모든 데이터는 친구 폰의 IndexedDB에만 저장. 서버 전송 없음.
- 합계와 굴비는 저장하지 않고 기록에서 매번 다시 계산.
- 삭제는 휴지통으로(30일 보관 후 앱 실행 시 영구 삭제). 영구 삭제·전체 초기화는 재확인(초기화는 ‘굴비’ 입력).
- 금액 1원~1억 원 정수, 메모 100자.
- 추가 투자는 막지 않고 경고 → 참기(굴비 +1, 하루 1회) 또는 사유 기록. 공격형 분류·키워드는 손실 동의 체크까지 필요.
- 백업은 JSON 파일. 기록 5건 이상이고 마지막 백업(없으면 첫 사용일)부터 7일이 지나면 홈에 알림.
